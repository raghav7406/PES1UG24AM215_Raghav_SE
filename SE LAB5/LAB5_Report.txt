5. REFLECTION ANSWERS
--------------------------------------------------------------------------------

Q1: What is the primary benefit of using static analysis tools before code execution?
A1: Static analysis allows developers to detect logic bugs, style inconsistencies, 
    and security flaws early in the software development lifecycle without executing 
    the code. This reduces debugging overhead and ensures code maintainability 
    across teams.

Q2: Why should weak cryptographic hashing algorithms like MD5 be avoided?
A2: MD5 is vulnerable to collision attacks, where two distinct inputs can yield 
    the exact same hash digest. Modern applications should use secure hashing 
    mechanisms such as SHA-256 to guarantee data integrity and security.

Q3: How does automated code checking (Pylint / Flake8) improve team collaboration?
A3: Automated linters enforce consistent styling standards (PEP 8) across the 
    entire codebase. This ensures uniform readability, eliminates personal 
    formatting disputes during code reviews, and simplifies onboarding for new 
    developers.
